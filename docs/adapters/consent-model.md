# External publication consent

Intent Commit distinguishes two commitments:

1. **Room commitment** — the author approves a statement for the current Intent Commit room.
2. **External publication approval** — the same author separately approves publishing that committed statement to a new audience or platform.

The second step is required because changing the audience changes the practical meaning and consequences of an utterance. A message may be appropriate for a bounded room without being intended for a public issue tracker.

An adapter therefore must not infer external consent from room membership, moderator authority, ownership, or the existence of a COMMITTED message alone.
